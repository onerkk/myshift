# 我的班表 · v323

v323 的 App 月曆與分享圖片都補齊前後月日期，形成連續的星期日到星期六，不再留下空白格。App 以月份標籤與較淡的立體卡片區分，點選可查看該日明細，再返回原月份；分享圖片以月／日區分。前後月的班別、節日、事項及已取得的匿名請假人數使用該日資料，本月天數與請假時數只統計選定月份。窄螢幕的日期與週末／假日標籤可換行。

v322 將分享圖片縮短為月份主卡、班別天數與月份班表，移除下方「本月事項與假別」清單。PNG 直接以 3840 px 寬繪製文字與圖形，保留陶瓷浮雕日期卡、照片雲層、季節葉片及晨光翡翠／暮色金邊兩種配色。月曆格內仍顯示節日、本人假別／時數及事項標示；＋N 與省略內容可回 App 查看完整明細。

分享前可預覽、放大、更新資料，並分開儲存原始 PNG 與開啟系統分享。匿名請假人數、0 人及尚未取得的「—」維持分開顯示。分享視窗可返回原頁，手機返回／前進也能操作。

v320 修正今天請假人數的深色對比，首頁主卡、七日班表與今天入口都會列出匿名人數；0 人、有人請假與資料尚未取得分開顯示。各主頁與日期、計薪、天氣、潮汐、設定、說明、統計及管理視窗加入固定返回操作。手機／瀏覽器返回鍵先關閉目前視窗，再回到前頁；月份、清單篩選、薪資期間、捲動、展開區塊及同帳號的暫存輸入保留。返回紀錄只存畫面識別碼，沒有上傳草稿。

天氣地點關閉後會解除畫面鎖定；逐時與潮汐日期按鈕改善深色對比及點擊大小。底部導覽列依實際高度預留空間，雷達載入／定位失敗及後台登入畫面也能返回班表。

## 既有計薪與資料功能

已保存的薪資與請假資料自動參與計算。日常操作只需要維護班表、調班與請假，不需要再次勾選公司規則或手動匯入已提供的薪資。

- 已提供的歷史薪資會在原帳號登入後自動讀取，首頁與薪資頁顯示一致。公司實領與班表估算分開呈現；不把歷史總額冒充公式已吻合。
- 固定薪資依生效日期保存；跨月加班與病假扣款依每日適用的薪資計算。後續調薪可在選填的變更區指定生效日。
- 每個薪資月都能在薪資設定中分開調整計薪起日與迄日；未自訂時維持上月 26 日至當月 25 日，兩端日期都計入。班表、請假、加班與夜點依該月範圍重算。
- 修改區間時會檢查與前後薪資月是否重疊或留下未分配日期，避免不知情地重複或漏算。固定月薪、固定扣款、月獎金及公司薪資條仍按薪資年月保存，不依未確認的公司規則按天拆分。
- 同時取得本人的歷史請假，避免切換月份、換單位或舊資料缺少 `ym` 時漏扣。
- 天災假保留既有給薪邏輯，但未出勤的晚班不再計入夜點出勤。
- 夜點自動比對完整的歷月薪資與出勤。只有單一候選規則能解釋至少兩個完整月份時才採用擬合結果；其他情況保留既有單價及估算標示。單月金額不能證明公司制度。
- 計薪視窗先顯示計算依據，變更欄位預設收合。移除逐項確認勾選及過期的匯入教學、重複網站副本。

尚未還原的部分：公司逐日假日給薪分類、完整夜點制度及部分歷史考勤差異。已有薪資條可正確顯示公司金額；未結算月份仍為估算，不能保證與公司完全相同。不得用月總額回填或修改實際請假來消除差額。
